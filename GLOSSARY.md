# Scoop Bus

Scoop Bus Run Club's website and its games. The games turn the club's runners into characters chased by the Scoop Bus.

## Language

### Run game

**Scoop Bus**:
The bus that chases runners along a course. It picks up (scoops) anyone it catches.
_Avoid_: Sweeper, chaser

**Scooped**:
Caught by the Scoop Bus, which takes a runner out of the race.
_Avoid_: Eliminated, dead, out

**Pacer**:
A computer-controlled runner sharing the course with the Players.
_Avoid_: Bot, AI, NPC, the pack (in prose)

**Character**:
The runner a Player races as: a club member or a custom runner. Each Character can be used by at most one Player per Room.
_Avoid_: Avatar, skin, runner (for the choice itself)

### Multiplayer

**Room**:
One multiplayer session that up to 8 Players join, identified by its Room Code.
_Avoid_: Lobby, game, server, session

**Room Code**:
The short code that identifies a Room and lets anyone join it, typed in or scanned as a QR code.
_Avoid_: Room ID, PIN

**Host**:
The device that owns a Room, runs the one true race and always shows it. It may have no Players of its own.
_Avoid_: Server, leader, screen

**Player**:
A person racing in a Room: a Local Player, a Phone Controller's player or a Remote Player.
_Avoid_: User, peer, client

**Local Player**:
A Player on the Host's own screen, using half of its keyboard or one of its gamepads.
_Avoid_: Couch player

**Phone Controller**:
A phone in the same room as the Host that acts only as one Player's controller and never shows the race.
_Avoid_: Pad, remote, controller app

**Remote Player**:
A Player on another device, usually over the internet, that shows the race itself and has its own controls.
_Avoid_: Online player, guest (guests are club visitors), client

**Round**:
One level raced by a Room's Players. It ends when only one Player hasn't been Scooped.
_Avoid_: Race, run (a run is single-player endless play), heat, match

**Standings**:
The points each Player has built up across a Room's Rounds, one point per Player outlasted.
_Avoid_: Leaderboard (that's club results), scoreboard, high scores

**Room List**:
The public list of open Rooms that Hosts have chosen to list.
_Avoid_: Lobby, server browser, matchmaking
