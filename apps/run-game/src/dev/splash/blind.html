Splash listening test

Fifteen versions of a splash sound for a game, in no particular order. Play each one (as often as you like), then write what you think: does it sound like water, is it too harsh, too quiet, which ones you like best.

Only reveal a name once you've written your notes for it. Keys 1–9 play sounds 1 to 9 when you're not typing.

Your notes are kept in this browser. Use “Copy all my notes” to send them.
