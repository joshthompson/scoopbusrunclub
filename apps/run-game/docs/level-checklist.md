# Level checklist

What each level has, in course order (`src/courses/index.ts`). ✅ means it has one, ⬜ means it still needs one.

- **Unique collectables**: fika and other pickups first seen on this level (`levelCollectables`). Hats and rides have their own columns.
- **Custom goal**: the level's `special` goal.
- **Unlockable character**: a runner unlocked on this level. Deri is unlocked by finishing every course, so he isn't listed.
- **Last art pass**: the date of the level's last `course-art-pass` (the skill), or ⬜ if it hasn't had one.
